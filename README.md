# Biblioteca Esotérica

Landing page dos guias digitais "Guia Místico das Ervas" e "A Sabedoria dos Cristais", feita com Next.js (App Router) e Tailwind CSS.

## Desenvolvimento

Requer Node.js 20.9 ou superior.

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Deploy na Vercel

Importe o repositório na Vercel; o preset **Next.js** é detectado automaticamente, sem configuração extra.

Opcional: defina `NEXT_PUBLIC_SITE_URL` (ex.: `https://seudominio.com.br`) para as URLs absolutas de Open Graph. Sem ela, é usado o domínio de produção da Vercel.
